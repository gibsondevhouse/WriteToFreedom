# UI field storage inventory

Generated by `npm run schema:documents` from UI templates and explicit nested contracts. Do not edit this file by hand.

The `document` column contains these named JSON fields; SQL identity, ownership, versions and timestamps stay outside that JSON. See [the audit](ui-persistence.md) for save/reload coverage and transient UI state.
